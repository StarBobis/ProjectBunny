# Resources

**XXMI DLL** extends 3DMigoto resource handling with additional metadata access and support for working with buffer regions.

## Topics

* [Resource Options](resource-options.md) — texture color-space configuration
* [Resource Metadata](resource-metadata.md) — resource identity and attributes such as size, stride, offset and more
* [Resource Regions](resource-regions.md) — existing buffer regions and explicit regions for `copy` and `ref` operations
* [Shader Declarations](shader-declarations.md) — original shader bytecode CB/SRV declarations
* [Texture Color Space](loading.md) — PNG/WIC and DDS interpretation.
