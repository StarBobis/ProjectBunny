# 【已推进】常驻CPU都在忙什么？

看一下当前项目常驻CPU都在忙什么，为什么会导致CPU热点问题，从而导致GPU命令无法及时执行，表现为GPU占用率从80%下降到9%，并且帧数下降严重，请给我一份性能优化可行性报告，但不要因为优化导致Mod无法正常生效或者Dump内容缺失。

能延迟解析的就延迟解析，我们本质上常驻的CPU开销中仅维持最小操作即可，完全没必要把复杂的操作提前在资源录制阶段就全部都做了，真正用到的时候再做反而更加合理。
