# 表达式

用于变量赋值、`if` 和支持表达式的选项。字符串路径、Hash 和所有静态选项并不会因此变成任意表达式。

## 运算符

从高到低：

| 优先级 | 运算 |
| --- | --- |
| 1 | 括号、函数、单目 `! ~ + -` |
| 2 | `**` 幂 |
| 3 | `* / // %` 乘、除、整除、余数 |
| 4 | `+ -` |
| 5 | `<< >>` |
| 6 | `< <= > >=` |
| 7 | `== != === !==` |
| 8–10 | 按位 AND `&`、XOR `^`、OR `\|` |
| 11–12 | 逻辑 AND `&&`、OR `\|\|` |

复杂条件加括号。`==` 比较数值，`===` 比较 float 的位模式（可区分正负零）；后者不是浮点容差比较。对测量值优先使用容差范围。

```ini
if $enabled && ($variant == 1 || $variant == 2)
    x = 1
endif
```

## 字面量与精度

支持十进制、`.5`、十六进制 `0x10`、二进制 `0b1010`，以及完整名称的 `DXGI_FORMAT_*`、`D3D11_BIND_*` 枚举。

INI 数值为 float32；所有整数在 `2^24` 以内可精确表示。二进制文本可接受 64 位，不代表变量能精确保留 64 位；位标志使用第 0–23 位。

```ini
[Constants]
global $flags = 0b0011

[CommandListToggleFlag]
$flags = $flags ^ 0b0010
```

## 函数

所有函数必须带括号，参数为一个表达式。

| 函数 | 用途 |
| --- | --- |
| `sin cos tan` | 三角函数 |
| `asin acos atan` | 反三角函数 |
| `abs sign` | 绝对值、符号 |
| `ceil floor trunc round frac` | 取整、截断、小数部分 |
| `sqrt rsqrt` | 平方根、平方根倒数 |
| `exp exp2 log log2` | 指数、对数 |
| `saturate` | 限制到 0–1 |
| `countbits` | 截断后按 uint32 计数置位数 |
| `random` | 有界伪随机数 |

`round` 的中点向远离零方向取整。`noise` 未实现。

`random(10)` 返回 `[0,10)`；`random(-10)` 返回 `(-10,0]`；零参数返回零。结果可能重复，不可用作唯一 ID。

```ini
[Constants]
global $pulse = 0

[Present]
$pulse = (sin(TIME) + 1) / 2
```

系统和渲染早期选项先于 `[Constants]` 解析，不能引用尚未声明的变量。支持静态表达式的资源选项只在解析时取快照。
