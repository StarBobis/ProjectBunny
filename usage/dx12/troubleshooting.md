# 排错

## 配置没有生效

1. 确认游戏使用 DX12，加载的是 `d3d12.dll`。
2. 检查进程工作目录与 DLL 目录是否各有一份 `d3dx.ini`；前者优先。
3. 检查 `[Include]` 与 `DISABLED*` 排除规则。
4. 按 F10，查看完成提示及错误数量。
5. 确认 Mod 已适配当前游戏的 DX12 版本。

更新 DLL 后必须重启游戏。

## 按键无效

让游戏处于前台，松开 Ctrl、Alt、Shift、Win 和小键盘 `.`，再按 F10。定位操作先用小键盘 0 开启，检查 Num Lock。

Mod 自定义按键还需检查重复绑定和 `condition`。

## 修改默认值无效

持久变量会恢复保存值。退出游戏，备份并移走配置指定的用户设置文件（默认 `d3dx_user.ini`），再启动。

## 画面异常或崩溃

先禁用全部 Mod，再重启。若恢复正常，逐个启用以定位触发项；若仍异常，恢复上一个 DLL 与配套配置对比。

## 收集诊断

提供游戏版本、DLL 版本、加载方式、触发步骤、相关 INI，并说明禁用 Mod 后的结果。

TIMING 版优先附上 DLL 部署目录的 `d3d12_log.txt`。日志较大时先读取尾部：

```powershell
Get-Content .\d3d12_log.txt -Tail 200
```

崩溃时如生成 `d3d12_crash_*.dmp` 或 `d3d12_crash_*.txt`，一并保留。并非每次崩溃都能生成报告。

每次复现后及时另存日志，避免下一次启动或部署覆盖。TIMING 构建脚本会把旧日志轮转为 `d3d12_log.before_*.txt`。
