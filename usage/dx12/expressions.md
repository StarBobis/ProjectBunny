# 变量与表达式

```ini
[Constants]
global $enabled = 1
global persist $variant = 0

[CommandListNext]
local $next = ($variant + 1) % 3
$variant = $next
```

`global` 为共享数值，`local` 属于调用作用域，`persist` 记录到用户设置文件。表达式与 DX11 一样使用 float32。数值和变量读入时舍入，每一步算术也按 float32 舍入。例如 `(16777216 + 1) - 16777216` 得到 0。

在 INI 表达式和命令列表赋值中，`x`、`y`、`z`、`w` 分别是第 0 个 IniParams 向量的四个分量。`x`、`x0` 和 `x00` 读写同一个值，`w0007` 和 `w7` 也等价。目前这些值供 CPU 端的 Mod 逻辑使用，向着色器绑定 IniParams 仍待实现。

## 运算

从高到低：

| 优先级 | 支持语法 |
| --- | --- |
| 1 | `()`、单目 `! ~ + -` |
| 2 | `**`，右结合 |
| 3 | `* / // %` |
| 4 | `+ -` |
| 5 | `<< >>` |
| 6 | `< <= > >=` |
| 7 | `== != === !==` |
| 8–10 | 按位与 `&`、异或 `^`、或 `\|`，依次降低 |
| 11–12 | 逻辑与 `&&`、或 `\|\|` |

`//` 为向下取整的除法，例如 `-3 // 2` 得到 −2。很小的非零除数仍然参与运算，例如 `1 / 0.00000025` 得到 4000000。`1 / 0` 得到正无穷，`1 / -0` 得到负无穷，`0 / 0` 和 `1 % 0` 得到 NaN。

`==` 和 `!=` 精确比较舍入后的数值，因此 `1 == 1.0000001` 为假，`0 == -0` 为真。NaN 与自身比较也不相等。`===` 和 `!==` 比较位模式，可以用 `0 !== -0` 区分正负零。条件判断中只有正零和负零为假。逻辑运算的短路范围由 [表达式配置](./configuration) 控制。

在文件头条件、数值配置或命令列表中，可以直接使用 DX11 Mod 的 `DXGI_FORMAT_*` 和 `D3D11_BIND_*` 常量，名称忽略大小写。例如 `DXGI_FORMAT_R8G8B8A8_UNORM` 等于 28，`D3D11_BIND_INDEX_BUFFER | D3D11_BIND_SHADER_RESOURCE` 等于 10。`DXGI_FORMAT_UNKNOWN` 是有效的零值；其他名称拼写错误会让整条表达式无效。

`0b101` 表示 5。二进制字面量最多可写 64 位，读入表达式时转换为 float32。`2**3**2` 的结果是 512，`-2**2` 的结果是 4。

函数接受一个表达式作为参数，可嵌套调用。例如 `$pulse = (sin(time) + 1) / 2`，`frac(-1.25)` 返回 0.75。函数的输入和结果使用 DX11 的 float32 精度。

| 用途 | 函数 |
| --- | --- |
| 三角与反三角 | `sin cos tan asin acos atan` |
| 符号、取整与小数部分 | `abs sign ceil floor trunc round frac` |
| 平方根、指数与对数 | `sqrt rsqrt exp exp2 log log2` |
| 限幅与计数 | `saturate` 限制到 0–1，`countbits` 统计转换后的 32 位整数中的置位数 |
| 随机数 | `random(8)` 返回大于等于 0 且小于 8 的值。`random(-8)` 返回大于 -8 且小于等于 0 的值 |

`random($bound)` 在每次执行时取样。零边界返回 0，NaN 或无穷边界返回 NaN，这些情况都不会消耗样本。在 `[Constants]` 初始化变量时取一次样，后续命令再次调用会取新样本。两次取样的结果可能相同。

`sqrt(-1)` 得到 NaN，`rsqrt(0)` 得到正无穷。当前仍缺少 `@/#/->` 和 Pool 访问。

例如 `$flags = $flags ^ (1 << 2)` 翻转第 2 位。位运算会先将操作数转为 float32，再向零截断为有符号 32 位整数，运算结果按 float32 舍入。右移保留符号位，移位数取低 5 位。连续存储标志位时请使用第 0–23 位，以免舍入丢失低位。

## 分支

```ini
[CommandListSelect]
if $variant == 0
    x0 = 0
else if $variant == 1
    x0 = 1
else
    x0 = 2
endif
```

`elif` 与 `else if` 都可用。每个分支必须闭合；没有通用循环语法。

## IniParams 与延后恢复

`x0/y0/z0/w0`、`x1/y1/...` 为着色器常量分量。

```ini
[Constants]
global $saved_x = 0

[CommandListTemporary]
$saved_x = x87
x87 = 1
post x87 = $saved_x
```

`post` 延后恢复到该调用的 post 阶段，不表示普通语句执行完就立刻恢复。只有配套着色器实际读取该分量时，设值才影响画面。

在 `[Constants]` 中写 `global locked $limit = 32` 可以声明只读值。命令列表和热键都能读取它。重复声明沿用第一次有效声明的值和标志。`locked` 与 `persist` 同时使用时，该值由 Mod 提供，不写入用户设置文件。

同名标量按 INI 命名空间区分。例如两个 Mod 都声明了 `$variant`，它们各自的热键只更改本 Mod 的值。跨 Mod 读取时写 `$\Example\variant`。旧 DX12 存档使用短名，加载时优先匹配根变量。没有根变量时，用旧值初始化各个同名的可写持久变量。下一次保存会分别写入完整名称。

持久值恢复默认的方法见[管理 Mod](./mods)。
